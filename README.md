# TizenPluto (Pluto TV AdBlock for TizenBrew)

TizenPluto is a lightweight TizenBrew app designed to improve the viewing experience on Pluto TV for Samsung Smart TVs. 

It intercepts server-side ad insertion (SSAI) on VOD content and uses ID3 metadata cues to mute and mask live TV ad breaks with a clean "Ad Break" slate, providing a seamless and quiet experience.

## Installation
1. Open **TizenBrew** on your Samsung TV.
2. Add a new repository/mod using this GitHub handle: `[DitBrugernavn]/[DitRepoNavn]`
3. Install **TizenPluto** from the list.
4. Launch the app directly from your Samsung Smart Hub Home menu.
